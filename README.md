# NovaTrust Investments

Initial runnable monorepo foundation for the NovaTrust public website and future client/admin portals.

## Requirements
- Node.js 20+
- pnpm 10+
- Docker (for PostgreSQL)

## Start
1. `pnpm install`
2. `docker compose up -d`
3. `pnpm dev`

The public site runs on the Next.js development server.

> This is a software foundation, not a production-ready financial/investment platform. Real-money transactions, KYC, custody, investment execution, and regulatory claims require appropriate licensed providers, security review, and legal/compliance work before launch.
